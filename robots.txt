# Robots.txt para Inteligência Brasil

# Política: conteúdo técnico aberto para crawlers tradicionais
# e de IA (training e answer engines). Objetivo é aparecer como
# referência em respostas de ChatGPT, Claude, Perplexity e Gemini.
#
# IMPORTANTE — por que não existem grupos "User-agent: X / Allow: /" aqui:
# cada robô obedece a UM único grupo (o mais específico que casa com seu nome)
# e ignora todos os outros, inclusive o grupo "*". Um grupo próprio contendo
# apenas "Allow: /" portanto NÃO acrescenta permissão nenhuma — ele apenas
# descarta os Disallow abaixo, e o robô passa a rastrear /x87g/, /cdn-cgi/,
# /.planning/ e PDFs. Googlebot, Bingbot, GPTBot, ClaudeBot, OAI-SearchBot,
# PerplexityBot, Applebot, CCBot, Google-Extended e cia. ficam liberados pelo
# "Allow: /" do grupo "*" — e só assim herdam também os Disallow.
# Ao adicionar um robô novo: NÃO crie um grupo só para liberá-lo. Crie grupo
# apenas se a regra for diferente do grupo "*" — e, nesse caso, repita nele
# todos os Disallow abaixo.

User-agent: *
Allow: /

# Salvaguarda preventiva: hoje nenhum PDF e publicado, mas se vier a ser,
# nao deve entrar no indice sem decisao explicita.
Disallow: /*.pdf$

# Endpoints internos do Cloudflare (ex.: /cdn-cgi/l/email-protection do Email
# Obfuscation). Nao sao paginas; evita URLs /cdn-cgi/* no indice.
Disallow: /cdn-cgi/

# Proxy first-party do Google Tag Manager. Nao e pagina; aparecia como
# "Rastreada, mas nao indexada" no Search Console. Ja serve X-Robots-Tag:
# noindex no header da Cloudflare; o Disallow evita o gasto de rastreamento.
Disallow: /x87g/

# Planejamento interno. Nunca foi publicado (gitignored), mas o Google tinha
# 5 URLs /.planning/seo-fase2/*.intro.html em 404 a partir do sitemap antigo.
Disallow: /.planning/
